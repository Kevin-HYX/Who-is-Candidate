# Store prompt files as internal resources

The preprocess LLM prompt is stored in `prompts/preprosess.md` instead of being embedded directly in Python code. The MCP guide is stored in `prompts/mcp-guide.md` instead of being embedded directly in Python code. The query generation guide is stored separately in `prompts/query-guide.md`. This makes prompt changes reviewable and keeps prompt text out of implementation logic.

The preprocess prompt file is an internal implementation resource owned by `preprocess.py`; it is not part of the CLI or MCP interface. `candidate://help` is generated by returning `prompts/mcp-guide.md` first and then `prompts/query-guide.md`. The evaluation loop manages reusable preprocess/query prompt artifacts separately under `test/data/prompts`; MCP guide text is not copied into that evaluation prompt artifact store. User Prompt Set creation snapshots the selected query prompt as `prompt_snapshot/query.md`. If preprocess prompt semantics change in a way that makes existing preprocessed profiles untrustworthy, `preprocess_schema_version` must be bumped so stale cache is discarded.
