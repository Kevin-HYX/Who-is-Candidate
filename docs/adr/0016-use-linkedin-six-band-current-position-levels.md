# Use LinkedIn Six-Band Current Position Levels

Candidate Search uses the [LinkedIn Recruiter seniority bands](https://www.linkedin.com/help/linkedin/answer/a415043) `Internship`, `Entry level`, `Associate`, `Mid-Senior level`, `Director`, and `Executive` as the ordered values of `seniority_level`. The field describes only the Primary Current Position: Manager maps to `Mid-Senior level`, no current position produces `unknown`, and Founder, Owner, Partner, Head, career length, credentials, professional capability, and management scope cannot independently determine the level. This replaces the project-owned eight-value ladder because it mixed ownership identities with hierarchy and created overlapping, non-comparable categories; the narrower six-band contract trades title precision for a more stable hard-filter boundary.
